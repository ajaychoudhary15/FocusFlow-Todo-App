# FocusFlow — To-Do App

A modern task management application built with React to help users organize daily tasks and improve productivity.

## Features

- Add, edit, and delete tasks
- Mark tasks as completed
- Organize tasks by category and priority
- Set task deadlines
- Search and filter tasks
- Track daily productivity with statistics
- Pomodoro focus timer
- Dark mode
- Export tasks to CSV
- Save tasks using browser LocalStorage
- Responsive dashboard design

## Tech Stack

- React.js
- JavaScript
- CSS
- Vite
- Browser LocalStorage

## Getting Started

1. Clone this repository.
2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

4. Open the local URL shown in your terminal.

## Project Purpose

Built as a frontend project to practice React components, state management, hooks, browser storage, and responsive UI design.
